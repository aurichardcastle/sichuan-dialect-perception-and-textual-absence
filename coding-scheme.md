### Category 1: Dialect Features

| Code | Definition | Decision Rule | Example |
|---|---|---|---|
| 1a: Lexical item | A word or phrase used in Sichuan dialect that does not exist in standard Mandarin or carries a different meaning | Code if the word would be unfamiliar to or understood differently by a Mandarin-only speaker from Beijing | 摆龙门阵 (*bai longmenzhen*) = "to chat"; Mandarin equivalent: 聊天 (*liaotian*) |
| 1b: Pronunciation marker | Written representation of Sichuan pronunciation differing from standard Mandarin | Code if the written lyric uses nonstandard characters or phonetic spellings that reflect Sichuan pronunciation | 啥子 (*sazi*) instead of standard 什么 (*shenme*) for "what" |
| 1c: Code-switch | A point where the lyricist switches between standard Mandarin and Sichuan dialect within a verse | Code at the transition point; both directions (Mandarin to dialect, dialect to Mandarin) count | A verse beginning in Mandarin that shifts to dialect at the start of a new couplet |
| 1d: Grammatical structure | A syntactic pattern characteristic of Sichuan dialect | Code if the sentence structure follows Sichuan grammar rules that differ from standard Mandarin | Use of 倒 (*dao*) as a verb complement where Mandarin uses 了 (*le*) |
